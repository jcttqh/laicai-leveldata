来财行动 · 关卡数据 H5（手机版）— 使用说明
=================================================

【最简单的运行方式：局域网自托管】
手机端零安装、零解压，只需浏览器打开一个地址。

步骤：
1. 在内网任意一台电脑上（本机即可），双击本目录下的 start.bat
   （或在本目录执行： python serve.py ）
2. 窗口会自动显示「手机访问地址」，形如：
       http://<本机IP>:8150/index.html
   本机当前 IP 探测为： 30.29.51.102
   （IP 可能随网络变化，以 start.bat 窗口实时显示的为准）
3. 手机连接与该电脑「同一 Wi-Fi / 同一局域网」
4. 手机浏览器输入上面的地址即可打开使用
5. 关闭该命令行窗口即停止服务

注意：
- 手机与电脑必须在同一网络（同一 Wi-Fi 或同一有线内网段）。
- 首次运行如弹出 Windows 防火墙提示，请勾选允许 Python 访问
  「专用网络 / 工作网络」，否则手机无法连入。
- 需要电脑保持开机且窗口不关。若想长期可访问，建议把本目录放到
  内网已有的 Web 服务器（nginx / IIS / Apache 的站点目录）上，
  这样无需每次手动启动、任何时间都能访问。

【操作方式（手机）】
- 单指拖动：旋转视角
- 双指捏合：放大 / 缩小
- 双指拖动：平移画面
- 右上角「复位」：回到初始视角；「透视 / 俯视」：切换投影
- 底部「数据内容」上滑：展开数据图层、时间轴、地图筛选

【本版本说明】
- 面向玩家的精简版，仅保留 3D 查看与数据图层。
- 已去除：脱离卡死数据、玩家撤离数据；以及开发用的模型调整 /
  操控速度 / 参考图 / 日志转表等面板。
- 首次加载数据较大（约 9MB 行为数据 + 快照 + 模型），
  手机首次打开稍慢属正常，之后有缓存会更快。
